# AI 3x Blueprint - Python

Hands-on Python practice exercises that build programming fundamentals step by step — from basic `print()` statements to keywords, variables, literals, data types, and user input.

## Project Structure

```
Python/
└── chapter_11_Python_Learning/
    ├── ex_01_Python_Basics/                  # Printing, comments, and the basics
    ├── ex_02_Keywords_Identifier_Variables/  # Keywords, identifiers, variables, math
    └── ex_03_Literals/                       # Literals, data types, user input, strings
```

Each exercise is a self-contained lab script that demonstrates a specific concept. See [chapter_11_Python_Learning/README.md](chapter_11_Python_Learning/README.md) for the full lab-by-lab breakdown.

## Getting Started

### Prerequisites

- Python 3.x installed

### Running the exercises

From the repo root, run any lab with:

```bash
python chapter_11_Python_Learning/ex_01_Python_Basics/Lab001_Hello.py
python chapter_11_Python_Learning/ex_02_Keywords_Identifier_Variables/Lab010_maths.py
python chapter_11_Python_Learning/ex_03_Literals/Lab023_Strings.py
```

Some exercises (e.g. `Lab021`, `Lab022`, `Lab023`) prompt for input — type your values and press Enter when prompted.

## Learning Path

1. Start with **ex_01** to get comfortable with `print()` and comments.
2. Move to **ex_02** to learn about keywords, identifiers, variables, and arithmetic.
3. Finish with **ex_03** for literals, data types, built-in functions, and user input.
