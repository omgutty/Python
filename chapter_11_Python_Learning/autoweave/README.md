# Autoweave - Playwright MCP Generated Tests

This folder contains end-to-end UI tests auto-generated by the **Playwright MCP** tool. The tests are written as `pytest` test cases using Playwright's Python sync API.

## Overview

| File | Description |
|------|-------------|
| `loginHR.py` | Sample login flow test (generated by Playwright MCP) |

## Prerequisites

- Python 3.12+ (managed by `uv` in this repo)
- `uv` installed (this project uses `uv` for environment and dependency management)

## Setup

### 1. Create a virtual environment

From the repo root (`D:\AI 3x Blueprint\Python`):

```bash
uv venv .venv --python 3.12
```

### 2. Install the test dependencies

```bash
uv pip install pytest playwright pytest-playwright
```

| Package | Purpose |
|---------|---------|
| `pytest` | Test runner |
| `playwright` | Browser automation library |
| `pytest-playwright` | Provides the `page` fixture used in tests |

> **Note:** The `pytest-playwright` plugin is required — the generated tests use `def test_...(page: Page)`, and the `page` fixture comes from this plugin, not from `pytest` or `playwright` alone.

### 3. Install the Playwright Chromium browser

Playwright does **not** ship browsers in its pip package — you must install one separately:

```bash
uv run playwright install chromium
```

## Running the tests

From the `autoweave` folder, run:

```bash
uv run pytest loginHR.py
```

To see detailed output:

```bash
uv run pytest loginHR.py -v
```

To run only the login test:

```bash
uv run pytest loginHR.py -k login
```

To run in a visible (headed) browser while debugging:

```bash
uv run pytest loginHR.py --headed
```

## Configuration

The generated test files contain placeholders that must be replaced with your real values before running:

| Placeholder | Replace with |
|-------------|--------------|
| `{{BASE_URL}}` | Your application's base URL, e.g. `https://your-app.example.com` |
| `{{USERNAME}}` | A valid login username |
| `{{PASSWORD}}` | The password for that username |

The generated tests run against a live application, so make sure the app is reachable at the configured URL before running.

## How Python was configured (what was done)

This section documents how the environment for running these tests was set up, so you can reproduce or verify it.

### 1. Python is managed by `uv`

The system Python 3.12 on this machine is managed by **uv** and is locked against plain `pip` installs (PEP 668 — you get an `error: externally-managed-environment` if you try). That is why a virtual environment is used instead of installing packages globally.

### 2. Virtual environment created

A `.venv` was created at the repo root:

```bash
uv venv .venv --python 3.12
```

Result: `D:\AI 3x Blueprint\Python\.venv`

### 3. Dependencies installed into the venv

```bash
uv pip install pytest playwright pytest-playwright
```

Result: `pytest 9.1.1`, `playwright 1.62.0`, `pytest-playwright 0.8.0`

### 4. Chromium browser installed

```bash
uv run playwright install chromium
```

Result: Chromium 1234 downloaded to `C:\Users\orgutty\AppData\Local\ms-playwright\`

### 5. IDE (VS Code) interpreter selected

The IDE needs to use the venv's Python so the `pytest` and `playwright` imports resolve:

1. Open VS Code on this repo
2. Press `Ctrl+Shift+P` to open the Command Palette
3. Type and select: **Python: Select Interpreter**
4. Choose the venv interpreter: `D:\AI 3x Blueprint\Python\.venv\Scripts\python.exe`
5. Open `loginHR.py` — the `import pytest` / `from playwright.sync_api import ...` errors should now be gone

### 6. Running the tests

From the `autoweave` folder, run with `uv run` so the venv is picked up automatically:

```bash
uv run pytest loginHR.py
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `import pytest` / `from playwright.sync_api import ...` not resolved | Make sure your IDE is using the `.venv` interpreter: `D:\AI 3x Blueprint\Python\.venv\Scripts\python.exe` |
| `Error: externally-managed-environment` on `pip install` | This Python is managed by `uv`. Use `uv pip install` inside the `.venv` instead of plain `pip` |
| Browser not found when running tests | Run `uv run playwright install chromium` once to download the browser |
| Tests run but nothing opens visually | Playwright defaults to headless mode. Pass `--headed` to open a visible browser window |
