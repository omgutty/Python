# 🐍 My Python journey — building toward AI agents

I'm learning Python with one goal in mind: **building AI agents**.

I'm not just watching tutorials — I'm writing real code every day. Here's what my practice repo looks like so far:

## The foundation (day by day)
- **Basics** — `print()`, comments, keywords, identifiers
- **Variables & math** — dynamic typing, BODMAS, built-in math functions
- **Literals & data types** — int, float, bool, complex, strings
- **Operators** — arithmetic, comparison, logical, ternary, membership
- **Control flow** — `if`/`elif`/`else`, `match` (Python's switch)
- **Loops** — `for`, `while`, `break`, `pass`
- **Functions** — parameters, returns, defaults, `*args`, keyword args
- **Scope & decorators** — local vs global, inner functions, decorators
- **Types & data structures** — type conversion, lambdas, lists, tuples

## Daily tasks to lock it in
- ✅ 3-number calculator (add / subtract / multiply / divide)
- ✅ Quotient & remainder with `//` and `%`
- ✅ Grade calculator (A–F)

## The fun part — browser automation
I also set up **Playwright + pytest** to automate real UI flows — an end-to-end login test that validates the whole session lifecycle (login → dashboard → logout → session invalidation).

## Why this matters for agents
Every agent is built on these same building blocks:
- **Functions** → tools an agent can call
- **Control flow** → the decisions an agent makes
- **Data structures** → the state an agent holds
- **Browser automation** → agents that can *act* on the web, not just answer

I'm documenting everything as I go — structure, setup, and how-to-run instructions — so the journey is reproducible and the next step is clear.

Next up: classes, files, and my first real agent prototype. 🚀
